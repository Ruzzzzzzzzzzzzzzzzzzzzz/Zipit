Client setup

    
Give every build your server address. If the server is behind a
      reverse proxy, start it with --public-url https://your-domain so this
      page shows the correct URL.

    
    
license:
  enabled: true
  file: "license.yml"
  publicKey: "public.pem"
  server: "{{PUBLIC_URL}}"
  require: true
  features:
    - audit

    

      
    

    
    
--license license.yml --license-key public.pem --license-server {{PUBLIC_URL}} --require-license

    

      
    

    
Or set the environment variable
      ZIPIT_LICENSE_SERVER={{PUBLIC_URL}}. Clients verify the RSA signature
      locally and use this server only for revocation and online validation.
